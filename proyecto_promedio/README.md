# Calculadora de promedio

Proyecto de Python de Isaac Alvarado Chaves para el curso Fundamentos de Tecnología Digitales, del profesor Adonis Aleman G.

El programa pide tres notas entre 0 y 100, calcula el promedio y lo muestra en pantalla. Utiliza variables, entrada de datos, operaciones y condicionales.

## Cómo ejecutarlo

Se necesita Python 3. Abra una terminal en la carpeta del proyecto y ejecute:

```bash
python main.py
```

Si el equipo utiliza el comando `python3`, ejecute `python3 main.py`.

Por ejemplo, con las notas 80, 90 y 100, el promedio es 90.0.

## Comandos de Git

- `git init`: inicia el repositorio en la carpeta del proyecto.
- `git add main.py README.md`: prepara los archivos.
- `git commit -m "Agregar calculadora de promedio"`: guarda la primera versión.
- `git branch -M main`: establece el nombre de la rama principal.
- `git remote add origin URL_DEL_REPOSITORIO`: vincula el repositorio de GitHub.
- `git push -u origin main`: sube los archivos a GitHub.
